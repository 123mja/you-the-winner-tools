When ON, visitors who are not signed in see a read-only demo using your Plans & Money data. When OFF, guests see an empty page.

When ON, each plan's status is a single "Completed" checkbox instead of the 5-option dropdown (Idea / Planning / Active / Completed / Archived), simpler for someone with special needs. Unchecked defaults to Planning.

How to set up user roles

User roles (admin vs user) are stored in Firebase under tools-you-the-winner/user-roles/{uid}.

To make someone an admin: sign in as them once, then go to Firebase Console → Realtime Database and set their UID to "admin" under user-roles/.

To create new users: go to Firebase Console → Authentication → Users → Add user.
